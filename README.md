# SQL---Business---Insights---Project-
This project contains SQL queries solving real- world business problems like customer analysis , invoice insights , and sales trend .

## 📌 Overview
This project contains a set of SQL queries designed to solve real-world business problems using a sample database.

## 📊 Features
- Analyze customer spending
- Identify top-performing cities
- Find highest invoices
- Determine best customers
- Country-wise invoice analysis

## 🛠️ Technologies Used
- SQL (Structured Query Language)

## 📂 Project Structure
- SQL file containing multiple queries (11 questions)
- Each query solves a specific business problem

## 🚀 Key Queries Included
1. Senior most employee based on job title
2. Countries with most invoices
3. Top 3 invoice values
4. City generating highest revenue
5. Best customer based on spending
...and more

## 🎯 Purpose
To practice SQL queries and gain insights from structured data.
